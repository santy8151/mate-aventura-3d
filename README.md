# MateAventura 3D — Videojuego Educativo 3D estilo Nintendo

Aplicación web educativa interactiva tipo **Duolingo + Super Mario Bros. Wonder / Nintendo 3D** enfocada en el aprendizaje de **proporciones, probabilidad, cálculo rápido y plano cartesiano**, con retroalimentación visual PBR 3D, efectos de sonido sintetizados mediante Web Audio API y sistema de recompensas.

## Niveles del Juego

1. **Nivel 1 — Batalla de Superhéroes con Aliados (Proporciones y Probabilidad)**:
   - Elige entre 3 aliados protectores (**Dino Verde**, **Princesa Estela**, **Capitán Champi**) que te defienden con su escudo 3D frente al gigante **Titán Caos-X**.
   - Resuelve 4 retos aleatorios de proporciones y probabilidad para lanzar ataques combinados.
2. **Nivel 2 — Carrera Matemática**:
   - Conduce un kart 3D por una autopista estilo Mario Kart usando flechas `←` / `→`, botones o clics directos en los carriles 3D.
3. **Nivel 3 — Mundo Mario Wonder: Plano Cartesiano 3D**:
   - Cuadrícula 3D interactiva (`X: 0..5`, `Y: 0..5`) con cámara panorámica amplia, tuberías, flores maravilla, arcoíris y castillo.
   - Ubica 4 tesoros usando coordenadas `(X, Y)` con flechas `← ↑ ↓ →`, cruceta o haciendo clic directamente en las casillas 3D mientras evolucionas hasta **Rey Coronado**.
4. **Nivel 4 — Búho Mentor (Situaciones de Probabilidad y Reflexión)**:
   - El Profesor Búho Sabio plantea situaciones reales para analizar qué es más probable que pase, recoge tu reflexión y entrega una Medalla y Certificado imprimible.
